## Rules / Regras

- Main signature: symbol on top, name below, centred. Prefer black or very dark backgrounds.
- Clear space: at least **0.10 × H** on every side, where H is the signature height.
- Minimum size: **240 px** wide on screens and **40 mm** in print. In a README, use **280–400 px** on a dark panel.
- The name is "Portal Gun". The lettering is drawn, not a font: never retype it or recompose the letters.
- Do **not** distort, tilt, recolour or remove parts. Do **not** add shadows, gradients, outlines or effects.
- Small avatars, such as the GitHub organization or repository icon, should use the symbol alone.
- Supporting typeface: DejaVu Sans (Regular/Bold), sans-serif fallback.
